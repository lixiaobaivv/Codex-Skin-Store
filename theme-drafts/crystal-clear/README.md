# Crystal Clear / 晶透玻璃

无背景图的高透明浅色主题草案。主题使用 `opaqueWindows: false` 与
`visualIntensity: "glass"`，尽量降低 Codex 内部壳层、侧栏、任务区和卡片的不透明度。

这套主题制造的是应用内部玻璃层次。Codex Desktop 的 Electron 原生窗口仍然是
非透明窗口，因此不会真正显示 macOS 桌面壁纸。

## 视觉参数

- 主色：`#32B9E8`
- 文字：`#25313C`
- 玻璃基色：`#F8FBFD`
- 无背景图、无环境粒子
- 卡片约 30% 不透明，任务区约 22%，窗口底色约 6%
